# Backlog

Idéer fra research på andre planleggingsapper (Zola, Joy, WeddingWire, RSVPify, Planning Pod m.fl.) og fra bruk. Prioritert grovt, øverst først.

## Neste opp

- [ ] **Følge og husstander.** Barn og voksne telles hver for seg. Husstand kan sitte samlet på bordplanen.
- [ ] **Budsjett og leverandører.** Estimert og faktisk beløp, depositum og betalingsfrister per tavle.
- [ ] **Tidslinje for dagen.** Program med klokkeslett og ansvarlig person, kan skrives ut.
- [ ] **Sorter oppgavekort.** Frist, prioritet eller navn per kolonne i tavlen.

## Senere

- [ ] **Svar per delarrangement.** Ulike gjestelister for for eksempel seremoni, middag og brunsj.
- [ ] **Advarsler i bordplanen.** Bord som er fullt, gjester som ikke bør sitte sammen, gjester uten plass. Vis svarstatus og matvalg ved hvert sete.
- [ ] **Innsjekk på arrangementsdagen.** Se bord og plass ved ankomst. Mest aktuelt for større arrangementer.
- [ ] **Maler.** Ferdige oppsett for bryllup, konfirmasjon og bedriftsfest, med kolonner og oppgaver.
- [ ] **Allergier på bordkortene.** Vis kostholdsbehov diskret på kort til kokk eller servering.

## Uavklart

- [ ] Nytt navn på «Lokale»-fanen i bordplanen (gulvplanen).
- [ ] Avsendernavn og e-postmaler for innloggingskoden i Supabase (settes manuelt, felles for orgit og sportsbibelen).
- [ ] E-postinnlogging for sportsbibelen (bruksanvisning er flyttet dit manuelt).
